# DataShip 1.0.0-rc.11

DataShip připravuje PDF přehledy z Jídelny SQL a umožňuje jejich plánované odesílání nebo ukládání na disk. Testovací verze pro Windows 10/11 x64, sestavení 20261029.12.

## Co umí

- Uložené přehledy s vlastním výběrem kategorií a více typů stravy, počty a volitelným seznamem strávníků.
- Více úloh, každou s vlastním časem, příjemci a pravidlem dne přehledu.
- Odesílání přes Resend/SMTP nebo pouze pravidelné ukládání PDF do zvolené složky.
- Jednorázový export uloženého přehledu přes parametr EXE bez GUI a bez e-mailu; vhodné pro zástupce na ploše.
- Službu Windows pro automatické úlohy při zavřené aplikaci, kontrolu a pokus o spuštění služby po uložení zapnuté úlohy, srozumitelná upozornění při chybě.
- Přímé otevření webu z DataShip.exe bez konzolového okna a bez VBS, odlišné ikony GUI a workeru, větší ovládání dní.
- Oddělená hesla administrace a databáze, viditelný stav uloženého a načteného API klíče, logy výsledků a odstranění služby z nastavení.

## Export uloženého přehledu

Do cíle zástupce lze zadat:

```text
"C:\DataShip\DataShip.exe" --export-report "mujprehled" --open-pdf
```

Použije dnešní datum a uložený obsah přehledu; web ani e-mail nespouští. Lze doplnit `--date 2026-11-02`, `--days-ahead 1` nebo `--output "C:\Prehledy\mujprehled.pdf"`. Přehled musí být v dané instalaci uložený. Podrobnosti: `docs/CLI_EXPORT_PREHLEDU.md` a přibalený `EXPORT_PREHLEDU.md`.

## Co je potřeba vědět

- Počítač musí být zapnutý, neuspaný a mít dostupnou databázi; e-mail potřebuje funkční odchozí službu a připojení.
- Varné dny se čtou z Jídelny SQL. Aplikace chybějící kalendáře nedoplňuje ani neodhaduje.
- Worker kontroluje úlohy přibližně po 30 sekundách a zpracovává je postupně. Nejde o odesílání přesně na sekundu; po pozdním spuštění může dohánět již splatné starší úlohy.
- Jednorázový export přes parametr nepřebírá čas ani pravidla varných dnů z plánované úlohy.
- Jde o testovací vydání. Skutečné doručení e-mailu už bylo potvrzeno na uživatelském Windows; nový režim exportu přes parametr a finální EXE je potřeba ověřit na cílovém počítači.

## Stažení a aktualizace

`DataShip-1.0.0-rc.11-Windows-x64-NSSM.zip` obsahuje také NSSM pro službu. Druhý ZIP je základní přenosný balíček. Rozbalujte vždy celý obsah včetně `_internal`.

Před výměnou souborů zastavte službu a ukončete GUI. Zálohujte instalaci a zachovejte své konfigurace, `.env`, `daily_reports.json`, úlohy a stav dokončených úloh. Ukázkovým configem je nepřepište. Aktualizujte GUI i worker a poté službu znovu spusťte. Nové distribuční ZIPy záměrně neobsahují vaše hesla, API klíč, přehledy ani příjemce.
