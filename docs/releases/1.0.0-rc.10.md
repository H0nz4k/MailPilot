# 1.0.0-rc.10 — Jednoduchý průvodce přehledem

- Čtyři kroky: datum a strava → obsah a PDF → cílový den → příjemci a čas.
- Výchozí datum dnes; součty nebo součty se jmenným seznamem.
- Čitelné konkrétní datum u pravidel včetně dalšího varného dne, podle skutečného kalendáře Jídelny.
- Jedno uložení do plánovače, bez odeslání e-mailu při ukládání.
- Úloha si pamatuje vlastní vzhled PDF; nové úlohy nemění přehledy používané jinými úlohami.
- Potvrzený běh/čekání a zpracovávání podle heartbeat workeru. Samotné uložení neznamená běžící službu.
- Při uložení po nastaveném čase se nová úloha spustí až následující den.

Aktualizujte současně GUI i worker. Postup a omezení: [DATASHIP_REPORT_WIZARD.md](../DATASHIP_REPORT_WIZARD.md).
