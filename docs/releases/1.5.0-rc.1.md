# DataShip 1.5.0-rc.1

- Nastavení zobrazuje stav služby podle Windows a při chybějící službě nabídne instalaci.
- Aktualizační balíček používá podepsaný manifest Ed25519 pro místní ZIP i GitHub Releases.
- Aktualizátor počká na dokončení přijaté úlohy workeru a při selhání výměny obnoví původní programové soubory.
- První převod staršího workeru vyžaduje jeho bezpečné zastavení. Pro použití podepsaných aktualizací je potřeba důvěryhodný veřejný klíč.

Postup přípravy klíče, aktualizace a zotavení je v `docs/DATASHIP_M6_UPDATES.md`.
