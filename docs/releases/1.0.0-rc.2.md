# DataShip 1.0.0-rc.2

Opravy prvního spuštění a Windows služby oproti rc.1:

- Cesta k NSSM se předvyplní vedle právě spuštěného EXE: `nssm\win64\nssm.exe`. Funguje i pro prázdnou uloženou cestu a přesunutý původní balíček.
- První připojení provede uživatele heslem správce DataShipu a formulářem pro ověření databáze. Následující spuštění automaticky ověří uložené spojení.
- Česká chybová a stavová hlášení NSSM, správné čtení jeho Unicode výstupu a jasná instrukce pro spuštění aplikace jako správce Windows.
- Přibalený NSSM je ve stejné struktuře i při lokálním buildu. Instalace služby ji sama nespouští.
- Windows build ověřuje také skutečnou instalaci, spuštění, stav a odstranění izolované zkušební služby, bez úloh a příjemců.

Stáhněte celý Windows-x64-NSSM ZIP, rozbalte ho do stálé složky a spusťte DataShip.exe. Pro instalaci služby musí samotné EXE běžet jako správce Windows. Heslo do nastavení aplikace tato oprávnění nenahrazuje. Podrobný postup je v přiloženém CTETE_ME.md.

Při aktualizaci zachovejte vlastní konfigurační soubory a přehledy. Před výměnou EXE zastavte existující službu a GUI; další službu stejné instalace nevytvářejte. Reálnou DB, e-mail a restart Windows ověřte podle KONTROLA_FUNKCI.md.
