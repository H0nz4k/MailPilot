# DataShip 1.0.0-rc.1

První testovací vydání nového webového rozhraní pro Windows 10/11 x64. Původní Qt MailPilot 12.8 se nemění.

- Uložené denní přehledy s vlastním výběrem kategorií a volbou v pravidelném odesílání.
- Opravené započítání hromadných objednávek z public.prihlasn do souhrnů a PDF.
- Jednotná hlavička s menu, větší text, kratší formuláře a potvrzené e-mailové adresy.
- Vlastní paleta barev, celé zvýrazněné rámečky a samostatné tučné nadpisy, texty a popisy.
- Samostatný plánovač DataShip-Worker.exe; volitelný balíček s NSSM.

Stáhněte celý Windows ZIP a rozbalte ho. DataShip.exe potřebuje přibalenou složku _internal. Druhý ZIP s příponou NSSM obsahuje navíc správce Windows služby. Python není na cílovém počítači potřeba.

Oba balíčky mají čistou ukázkovou konfiguraci. Při aktualizaci zachovejte vlastní provozní soubory; službu před výměnou zastavte. Automatická instalace ani spuštění služby neprobíhá.

Před produkčním nasazením proveďte přiloženou KONTROLA_FUNKCI.md včetně porovnání počtů/částek s vaší DB, skutečného e-mailu a restartu Windows. Nepodporované staré souhrnné úlohy ani automatické opakování chyb nového workeru v témže dni nejsou součástí této verze.

Kontrolní součty souborů: SHA256SUMS.txt. Verze a přesný zdrojový commit: BUILD_INFO.json uvnitř ZIPu.
