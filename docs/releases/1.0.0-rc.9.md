# DataShip 1.0.0-rc.9

## Novinky a opravy

- **Varné dny: skutečné názvy typů služby z JídelnaSQL.** Plánovač při výpočtu následujícího varného dne používá `public.varnedny` a přesnou shodu zvoleného `typsluzby`, například `Oběd-A`, `Oběd MŠ`, `Večeře` nebo zcela vlastní označení.
- Odstraněn chybný implicitní předpoklad, že typ se jmenuje `Oběd`, a jakékoli odvozování podle textové předpony. Není používán seznam názvů natvrdo.
- **Odesílání → Upravit → Kalendáře varných dnů – JídelnaSQL:** můžete použít kalendář podle uloženého přehledu, explicitně všechny kalendáře nebo jeden či více vybraných z databáze.
- Filtr obsahu PDF a kalendář pro výpočet data odesílání jsou oddělené volby. Změna kalendáře nemění zvolené kategorie ani obsah uloženého přehledu.
- Chybějící nebo neplatný kalendář nezpůsobí automatický výběr podobného typu, ale srozumitelnou chybu. Pokud je vybraných více kalendářů, hledá se nejbližší datum s `A` alespoň v jednom z **vybraných**.
- Při instalaci není výchozím kalendářem smyšlené `Oběd`. Existující úlohy a jejich uložené nastavení zůstávají nedotčené.
- Doplněné regresní testy libovolných názvů služby, kombinací více kalendářů, chybějících záznamů a zachování historických úloh.

## Aktualizace Windows / NSSM

Balíčky pro **Windows x64**:

- `DataShip-1.0.0-rc.9-Windows-x64.zip` – GUI + samostatný Worker.
- `DataShip-1.0.0-rc.9-Windows-x64-NSSM.zip` – totéž + NSSM pro správu Windows služby.

1. Před aktualizací **zastavte starou NSSM službu** a ukončete GUI. Neinstalujte paralelně druhou službu ke stejným úlohám.
2. Zálohujte `config.json`, `daily_reports.json`, `web_mail_tasks.json`, `web_mail_settings.json`, `web_mail_worker_state.json` a další místní nastavení, logy a přístupové údaje. **Nemažte `web_mail_worker_state.json`**, protože byste riskovali opakované rozeslání.
3. Rozbalte celý balíček včetně `DataShip.exe` a `DataShip-Worker.exe`. Zachovejte dosavadní provozní soubory; nepřepisujte je ukázkovými konfiguracemi. Při přesunu aplikace opravte cesty **zastavené** NSSM služby.
4. V aplikaci otevřete **Odesílání přehledů** a u úloh s dříve přednastaveným neexistujícím `Oběd` vyberte **Upravit → Kalendáře varných dnů → Jen vybrané kalendáře**. Ze skutečných dat JídelnaSQL zvolte příslušné služby a uložte. Nebudou-li typy odpovídat, úloha se při výpočtu data bezpečně zastaví s chybou.
5. Ověřte předpovězené cílové datum, obsah uložených přehledů, příjemce a čas odeslání. Službu spusťte až potom. **Start Workeru může hned vyvolat splatné úlohy.**

## Ověření

Windows CI spouští kompletní regresní testy, sestavení obou EXE, smoke test hotového GUI/Workeru a izolovaný test NSSM bez rozeslání reálných e-mailů. Funkčnost se skutečnými provozními údaji JídelnaSQL a účtem Windows služby musí ověřit provozovatel.
