# DataShip 1.2.1-rc.1 — testovací verze

- Nový PDF přehled podle typu výdeje, kategorie a menu, s volitelným názvem pokrmu.
- Sazby se vybírají podle platnosti k datu přehledu; nejednoznačné typy výdeje se hlásí jako chyba.
- Upravená barevná schémata a přehlednější editor barev.

Před aktualizací zálohujte instalaci a zachovejte konfiguraci, uložené přehledy a úlohy. Nejdříve vyzkoušejte na testovací kopii databáze. Skutečné zasílání e-mailů a účet služby zákazníka nebyly ověřeny.

Úplná regresní sada obsahuje starší nesoulad testů nastavení e-mailu; výsledek plné sady je viditelný v GitHub Actions. Cílené testy nové funkce musí projít.
