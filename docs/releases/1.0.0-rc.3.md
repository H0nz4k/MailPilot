# DataShip 1.0.0-rc.3

Každé pravidelné odesílání může mít vlastní kalendář varných dnů.

- V **E-maily → Upravit / Nové odesílání → Za který den? → Následující varný den** vyberte **Kalendář varných dnů**. Například Oběd a Večeře tak mohou určit různá data.
- Nabídka se načítá ze skutečně nastavených kalendářů Jídelny. Nové odesílání vyžaduje výslovný výběr; chybějící kalendář se nenahradí jiným typem stravy.
- Výběr zůstane uložený při restartu, úpravě i kopírování. Obsah PDF se dál řídí vybraným přehledem.
- Starší odesílání zachovají svůj dosavadní společný kalendář. Při úpravě se předvyplní a po uložení se přiřadí přímo tomuto odesílání.
- Původní společné nastavení je schované v sekci **Kalendář starších odesílání**.

Při aktualizaci zastavte GUI i existující NSSM službu, zazálohujte původní instalaci a aktualizujte **GUI i DataShip-Worker.exe**. Zachovejte vlastní konfiguraci, přehledy a úlohy; potom spusťte stejnou službu znovu. Starší worker vlastní kalendář úlohy nezná. Druhou službu nevytvářejte.

Balíček Windows-x64-NSSM obsahuje vše potřebné včetně NSSM. Automatické testy ověřují samostatné kalendáře i kompatibilitu starších úloh; reálnou DB a plánované odeslání ověřte podle přiloženého KONTROLA_FUNKCI.md.
